Digital Devil Saga - Translation Tool

Gestion complète de l'ISO, Extraction et Recompilation

Progression 0%

A Extraction de l'ISO

Extrait DDS3.IMG, DDS3.DDT et les fichiers systèmes de l'ISO originale.

B Extraction Rapide des Scripts (.bmd / .bf)

Extrait uniquement les fichiers contenant du texte depuis l'archive DDS3.IMG pour un gain de temps maximal.

C Génération des Fichiers JSON

Génère les fichiers JSON traduisibles avec la gestion des choix [sel] et des noms de fichiers originaux.

D Encodage des Traductions

Reconvertit vos fichiers JSON traduits (dans `traduction/scripts`) au format binaire du jeu (.bf / .bmd).

L'encodage injecte vos textes français directement dans les fichiers `.bmd`/`.bf` de `dds3data/`.

E Reconstruire DDS3.IMG

Recompile l'archive principale du jeu et régénère la table d'indexation (DDS3.DDT) avec vos scripts modifiés.

F Générer l'ISO Traduite

Injecte les fichiers systèmes et DDS3 modifiés dans une toute nouvelle image ISO jouable.
